# Calculadora de Ahorro Mensual

Una calculadora que permite saber cuánto dinero queda disponible al mes después de restar gastos e inversión.

---

## Objetivo del proyecto

El objetivo es construir un programa que pida al usuario tres datos:

- Sueldo mensual
- Gastos mensuales
- Inversión mensual

Con esos datos, el programa calcula el ahorro mensual real:

```txt
ahorro = sueldo - gastos - inversión
